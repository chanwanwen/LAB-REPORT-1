A Streamlit application that runs breadth-first search (BFS) and depth-first search (DFS) on a directed graph and breaks ties alphabetically.

Live App: https://lab-report-1-sodpbfkbxfmtftdtjpfptb.streamlit.app/

<img width="1917" height="906" alt="image" src="https://github.com/user-attachments/assets/cd56cf75-3cde-4492-993f-fd35b94e5369" />

Both algorithms start from a selected node and follow directed edges to discover reachable nodes. When multiple adjacent nodes are available, alphabetical tie-breaking is applied to determine the order of exploration.

The application provides a visual representation of the graph traversal process and displays the expansion order, node levels, parent relationships, frontier contents, and search paths.
